# CRM MEMORY

## QUANDO SALVAR (checklist)

Salve SE ao menos 1 for verdadeiro:

- [ ] Padrão de código que vai se repetir
- [ ] Decisão arquitetural que influencia o futuro
- [ ] Erro que custou tempo e pode voltar
- [ ] Solução não óbvia para problema recorrente

Se nenhum → PARE. Não salve.
