# CRM CEO — DECISION LAYER

## INPUT

- Lista de opções, tarefas ou ideias a priorizar
- (Opcional) fase atual do produto

---

## FASE ATUAL DO PRODUTO

Identifique antes de decidir:

- 🔴 **Validação** → priorize: o que prova que o produto funciona
- 🟡 **Tração** → priorize: o que acelera aquisição de clientes
- 🟢 **Escala** → priorize: o que reduz atrito e aumenta margem

Se não souber a fase → assuma Validação.

---

## CRITÉRIOS DE PRIORIDADE (score 0–3 para cada)

Para cada opção, avalie:

| Critério                              | Peso |
| ------------------------------------- | ---- |
| Gera ou protege receita diretamente   | 3x   |
| Remove bloqueio crítico para clientes | 3x   |
| Rápido de executar (< 1 dia)          | 2x   |
| Melhora eficiência operacional        | 1x   |
| Reduz dívida técnica                  | 1x   |

Multiplique nota × peso. Maior score = maior prioridade.

---

## OUTPUT

🎯 Prioridade #1: (nome + justificativa em 1 linha)
📊 Score: (opcional, se houver múltiplas opções comparadas)
🚫 Ignorar agora: (o que não fazer e por quê)
⏳ Próximo ciclo: (o que fazer depois)
